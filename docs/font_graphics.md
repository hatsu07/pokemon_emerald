# フォント・グラフィック解析

このドキュメントは、日本版『ポケットモンスター エメラルド』のフォントとグラフィックに関する解析情報をまとめます。

## 文字コード体系

日本版は `charmap.txt` で定義された1バイト文字コードを使用しています。

### 文字コードの特徴

| 区分 | コード範囲 | 備考 |
|---|---|---|
| ひらがな | `0x01` ~ `0x50` | 清音・濁音・半濁音・促音・小文字 |
| カタカナ | `0x51` ~ `0xA0` | 清音・濁音・半濁音・促音・小文字 |
| 数字 | `0xA1` ~ `0xAA` | `0`〜`9` |
| 記号 | `0xAB` ~ `0xB9` | `!` `?` `.` `-` `…` `「` `」` `♂` `♀` `¥` `,` `×` `/` |
| 英字大文字 | `0xBB` ~ `0xD4` | `A`〜`Z` |
| 英字小文字 | `0xD5` ~ `0xEE` | `a`〜`z` |
| 特殊文字 | `0xF1` ~ `0xF6` | `Ä` `Ö` `Ü` `ä` `ö` `ü` |
| 制御コード | `0xF9` ~ `0xFF` | 矢印・特殊記号・終端 |

### 制御コード

| コード | 記法 | 意味 |
|---|---|---|
| `0xFA` | `\l` | 行スクロール |
| `0xFB` | `\p` | 段落送り（ボタン待ち） |
| `0xFC 0x0C 0xFB` | `TALL_PLUS` | 特殊記号 |
| `0xFD 0x01` | `{PLAYER}` | プレイヤー名 |
| `0xFD 0x02` | `{STR_VAR_1}` | 文字列変数1 |
| `0xFD 0x05` | `{KUN}` | 「くん」/「ちゃん」 |
| `0xFD 0x06` | `{RIVAL}` | ライバル名 |
| `0xFE` | `\n` | 改行 |
| `0xFF` | `$` | 文字列終端 |

### 英語版との違い

日本版の制御コードは英語版（US版）と異なります：

| 機能 | 日本版 | 英語版 |
|---|---|---|
| 段落送り | `0xFB` | `0xFC 0x09` |
| 改行 | `0xFE` | 同様 |
| 終端 | `0xFF` | 同様 |
| フォント切替 `{JPN}` | **未使用** | Expansionで使用 |

日本版オリジナルROMでは `{JPN}`（`FC 15`）フォント切替コードは使われていません。

## フォントデータ

フォントデータは `data/data.s` 内の `.incbin` ブロックに格納されています。
現時点では未抽出・未解析の状態です。

### フォント関連のデータ領域（推定）

| 内容 | 推定ROM領域 | 備考 |
|---|---|---|
| 半角フォント（英数字・記号） | 未特定 | 主にUI・バトル画面で使用 |
| 全角フォント（ひらがな・カタカナ） | 未特定 | メッセージ表示で使用 |
| フォント幅テーブル | 未特定 | 各文字の表示幅を定義 |
| フォント色テーブル | 未特定 | 文字色・影色を定義 |

### フォント解析の課題

1. **フォントデータの場所特定**: `data/data.s` 内のどのincbinブロックがフォントか特定する必要がある
2. **文字コードとグリフの対応**: charmap.txt のコード値とフォントテーブルのインデックスが一致するか確認
3. **幅テーブルの解析**: 可変幅フォントの場合、各文字の幅テーブルを解析する必要がある
4. **色データ**: フォントの色・影・光沢などの描画パラメータ

## グラフィックデータ

グラフィックデータは主に `data/data.s` に格納されています。

### グラフィック種別

| 種別 | 形式 | 備考 |
|---|---|---|
| タイルセット | 4bpp/8bpp タイル | マップ・フィールドで使用 |
| スプライト | 4bpp タイル + OAM | キャラクター・ポケモン |
| パレット | 16色/256色 | 色定義 |
| 背景 | 4bpp/8bpp タイルマップ | 戦闘背景・タイトル画面 |
| ウィンドウ | 4bpp タイル | メニュー・メッセージボックス |

### グラフィックツール

`tools/` ディレクトリには以下のグラフィック関連ツールがあります：

| ツール | 用途 |
|---|---|
| `tools/gbagfx/` | GBA用グラフィック変換（expansion側で利用） |
| `tools/preproc/preproc` | テキスト・制御コードのバイナリ変換 |

将来的には Porymap（マップエディタ）や Porytiles（タイルエディタ）の日本語版対応を予定しています。

## 今後の解析計画

1. **フォントデータの特定**
   - `data/data.s` の incbin ブロックを調査
   - 各ブロックの先頭バイトパターンからフォントデータを識別
   - 文字コードとグリフの対応を確認

2. **フォント幅テーブルの解析**
   - 各文字の表示幅を定義するテーブルを特定
   - 日本語文字の可変幅対応を確認

3. **グラフィックデータのマッピング**
   - 各 incbin ブロックがどのグラフィックに対応するか特定
   - ツール連携（gbagfx等）の準備

4. **フォント改変手順の確立**
   - フォントデータの抽出・編集・再構築手順
   - 新規フォントの追加方法
